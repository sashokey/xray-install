## Proxy server (slave)

[setup-proxy.sh](setup-proxy.sh) sets up the chain `client -> slave -> main` using the VLESS + TLS + Vision link generated by [setup.sh](setup.sh). Run it on the slave; the existing main server does not need any changes.

Use a clean Debian 13 (Trixie) server as root. Point a separate domain A record to the slave, remove its AAAA record, and allow inbound TCP ports 80 and 443.

```bash
curl -4fsSL https://raw.githubusercontent.com/sashokey/xray-install/master/setup-proxy.sh -o setup-proxy.sh && bash setup-proxy.sh
```

Enter the slave domain, enter a UUID or press Enter to generate one, and paste the existing main VLESS link when prompted. The main link input is hidden. Import the displayed slave VLESS link into your client.

All proxied client traffic goes through main. If main is unavailable, the slave does not fall back to a direct connection. Main's existing routing rules still apply.

Repeated installation reuses the saved slave UUID and any existing unexpired certificate. SSH remains available. Certificate renewal and daily Xray update checks are configured automatically.

Check the connection chain:

```bash
/usr/local/sbin/xray-proxy-setup --check
```

Check for an Xray update manually:

```bash
/usr/local/sbin/xray-proxy-setup --update
```
